# VietNote Design Philosophy

Read this before creating or changing any UI (landing page, web app, Chrome extension, desktop apps). The goal is that any agent or designer produces screens that feel like the same product. Code source of truth: `web/assets/css/main.css` (tokens + primitives) and `web/components/`. If this document and the code disagree, fix whichever is wrong and keep them in sync.

## 1. The feeling in one line

**A well-kept paper notebook, typeset by someone who cares.** Warm paper, black ink, one red-ink accent, a serif voice, small mono labels like margin annotations. It must feel made by a person for people who take notes, not generated by a template.

## 2. What we are deliberately NOT (the "AI theme" list)

These patterns make a site look like every generated SaaS page. Do not use them:

- Purple/blue/pink gradients, glows, glassmorphism, blurred blobs, neon accents, dark navy "futuristic" backgrounds.
- Sparkle/magic-wand icons and "AI-powered" framing. We describe the job (meetings, lectures, notes), not the technology.
- Rows of three identical rounded cards, each with an icon tile; centered-everything layouts; pill buttons; big rounded corners.
- Generic dashboard screenshots with fake metrics, fake logos, fake testimonials, "trusted by" strips, invented statistics.
- Inter/system sans for every heading, uniform 400/600 weights, uppercase eyebrow labels over every heading in brand blue.
- Emoji, mixed icon sets, stock illustrations, 3D art.

## 3. Principles

1. **Paper and ink.** Cream paper background with a faint grain, near-black warm ink, hairline black rules. Depth comes from stacking and rotation like real sheets (a slightly tilted note on a second sheet), and from hard offset shadows, never soft glowing ones.
2. **One accent: vermilion.** `--accent` (red ink, like a Vietnamese seal stamp) is the only brand color. Use it for the seal logo, section numbers, the hand-drawn underline in the headline, active/"in progress" markers, tags that need attention and focus rings. Highlighter yellow (`--mark`) is the only other color, used strictly for English terms and the active option in a menu.
3. **Typography is the identity.** Serif display (Newsreader) for headlines, section titles and numerals, with italic for emphasis. Sans (Be Vietnam Pro, designed for Vietnamese) for body. Mono (IBM Plex Mono) for labels, timestamps, status and the top strip. A handwriting face (Patrick Hand) appears only for tiny margin scribbles. All four support full Vietnamese.
4. **Editorial structure, not cards.** Content is organised like a printed document: numbered section labels (`01 ── VÌ SAO`), ruled lists, a ledger table for features, a table of contents with dotted leaders for progress, asymmetrical two-column splits with a sticky heading. Prefer rules and whitespace over boxes.
5. **Human marks.** Small crafted details signal a person made this: a hand-drawn SVG underline, a rubber-stamp "Sample" label, a margin scrawl, struck-through filler words, highlighter marks. Use them sparingly (a few per page), never as wallpaper.
6. **Show the work honestly.** Demonstrate the product with typeset examples (speech to notes, a sheet of notes) clearly labelled as illustrations. **Never invent metrics, customers, logos, quotes or accuracy figures.** Status is stated plainly (`Đang làm`, `Sắp tới`, `Dự kiến`) and must match `ROADMAP.md`.
7. **Vietnamese first.** Every string exists in `vi` and `en`. Layouts must survive long Vietnamese words and stacked diacritics: line-height at least 1.1 for display, 1.6 for body, no fixed text heights, no all-caps for long text.
8. **Provenance is part of the brand.** The line "Từ lập trình viên của NoteVN.com và NoteOp.com" (en: "From the developers of NoteVN.com and NoteOp.com") appears in the top strip of every page, as the large statement in the makers section, and in the footer. It is rendered by `MakerLine.vue`; links are defined once in `MAKER_LINKS` in `useCopy.ts`. Do not paraphrase it or make claims about those products.
9. **Accessible by default.** 4.5:1 contrast for text, visible focus rings (2px accent), full keyboard support, `prefers-reduced-motion` respected, real labels and ARIA.
10. **Quiet motion.** Only functional: 120-150 ms fades on popovers, color changes on hover. No parallax, scroll-jacking, floating or bouncing elements.

## 4. Tokens

All in `:root` of `main.css`. Use variables, not hard-coded values, in new CSS.

| Token | Value | Use |
| --- | --- | --- |
| `--paper` | `#f5f0e6` | Page background (with grain) |
| `--paper-2` | `#ebe3d2` | Alternate section background, row hover |
| `--field` | `#fffdf7` | Inputs, note sheet, menus, "clean notes" panel |
| `--ink` | `#1d1b17` | Text, rules, dark bands, primary button |
| `--ink-2` | `#5a554b` | Body copy, secondary text (6.5:1 on paper) |
| `--ink-3` | `#6b6559` | Placeholders, captions, meta (4.6:1 on paper) |
| `--rule` | `#d6cdb9` | Soft separators |
| `--accent` | `#b8321c` | Red ink accent (5.3:1 on paper) |
| `--accent-soft` | `#ff8a73` | Accent on dark bands (7.5:1 on ink) |
| `--mark` | `#ffe27a` | Highlighter |
| `--ok` | `#2f6b3b` | "Done" status only |
| `--r` | `2px` | The only corner radius (seal logo and stamp use 3px) |
| `--control-h` | `52px` | Inputs, selects, primary buttons |
| `--wrap`, `--gutter` | `1160px`, `28px` (20px on phones) | Page container |

**Type scale**
- Display (Newsreader, 500): h1 `clamp(42px, 5.4vw, 74px)` / 1.1 / -0.025em, emphasis in italic with the hand-drawn underline; h2 `clamp(32px, 4.2vw, 52px)` / 1.1 / -0.02em; item titles 22-26px; closing CTA is italic.
- Body (Be Vietnam Pro 400/500/600): 16px / 1.65; lead 18px; small 13-15px.
- Mono (IBM Plex Mono 400/500): 11.5-12.5px, uppercase with 0.08-0.12em tracking for labels and statuses.
- Handwriting (Patrick Hand): 19px, only inside the note sheet.

**Spacing:** sections 112px vertical (80px under 1000px); list rows 18-32px; hero grid gap 72px. Keep to a 4/8px rhythm.

## 5. Page anatomy (landing)

1. **Top strip** (ink bar, mono 12.5px): the maker line with underlined links.
2. **Masthead** (sticky, paper, 1px ink bottom rule): seal-logo + serif wordmark, text nav, language toggle (globe + EN/VI), underlined "Đăng ký" link. No filled nav button.
3. **Hero:** 7/5 split. Left: status line (red dot + mono), serif headline with the key phrase in italic + hand-drawn underline, lead, form, planned platforms list. Right: `NotePage` (tilted ruled sheet on a second sheet, stamp, highlighted English terms, checkbox list, handwritten scrawl).
4. **01 Why:** sticky heading left; numbered principles right (italic red numerals, ruled rows, mono tag).
5. **02 Example** (`paper-2` band): dashed "Speech" box with struck-through filler words, accent arrow, solid "Notes" box with hard offset shadow. Caption states it is an illustration.
6. **03 Features:** ledger table (title, description, status marker), hover tint.
7. **04 Makers** (ink band): the maker line as a large serif statement, short note, links to both sites.
8. **05 Progress:** table of contents with dotted leaders and status markers.
9. **Closing CTA** (ink band): italic serif title + form in dark tone.
10. **Colophon:** mono footer with copyright/status and the maker line.

Alternate paper / paper-2 / ink to separate sections; at most three ink bands (top strip, makers, CTA).

## 6. Components

| Component | Rule |
| --- | --- |
| `SectionHead` | Mono label `NN ── LABEL` (red number, short black rule) above a serif h2, optional grey lead. |
| Buttons | Square (2px). `.btn-ink`: ink fill, paper text, accent on hover. `.btn-paper`: paper fill, ink text (on dark bands). Always followed by a Lucide arrow. One primary action per area. No pills, no gradients. |
| Inputs | 52px, 1.5px ink border, `--field` fill, 2px radius, visible labels above in mono uppercase. Focus = 2px accent outline offset 2px. On dark bands: transparent fill, paper border (set by `.tone-dark`). |
| `AppSelect` | Custom accessible listbox (never a native `<select>`). Trigger looks like an input with a chevron. Menu: `--field` background, 1.5px ink border, 5px hard offset shadow, active row highlighted in `--mark`, chosen row bold with an accent check; the empty option is the grey placeholder. Opens upward when space is short. Keyboard: Enter/Space/ArrowDown open; arrows, Home, End move; Enter/Space choose; Esc closes and returns focus; Tab closes; type-ahead. Emits a hidden input when `name` is set. |
| Status marker | Mono uppercase text with a small square: filled accent = in progress, filled green = done, half-filled ink = next, hollow = planned. |
| Ruled list | 1px ink rules between items, serif titles, grey descriptions; no card backgrounds. |
| `NotePage` | `--field` sheet with faint ruled lines and a red margin line, 1.4deg tilt, a second sheet behind at -2.6deg, soft paper shadow, rubber-stamp label in accent. |
| English terms | Always highlighted with `<mark>` (lower-half yellow highlighter), in transcripts, examples and notes. |
| `MakerLine` | The provenance line; `arrow` prop adds the small external-link arrow in the top strip. |

## 7. Icons and imagery

- **Icons: Lucide only** (`lucide-vue-next`), 1.5-2px stroke, used sparingly and mostly as arrows, checkboxes and the globe. No emoji, no icon tiles, no mixed sets.
- Illustrations are typeset (the note sheet, the speech-to-notes pair). Real screenshots may be added later in a paper frame with the same stamp/shadow rules.
- Arrows in running text (`←`, `→`) are typography and fine.

## 8. Voice and copy

- Plain, specific, calm; short sentences; speak about work situations (meeting, lecture, video), not about "AI". No superlatives without proof, no fake urgency, no jargon (WER, ASR) on public pages.
- Headline pattern: a concrete promise with the payoff phrase in italic and underlined.
- All copy lives in `web/composables/useCopy.ts` (`vi` and `en`, same shape). Do not hard-code strings in components.

## 9. Other surfaces (extension, desktop apps, web app)

- Reuse the tokens: paper/field surfaces, ink text, mono for timestamps and status, accent for the recording/active state, 2px corners, hairline rules, Lucide icons.
- Compact density is fine (40-44px controls, 13-14px body) but keep the serif for titles and the highlighter for English terms; the transcript view should look like the note sheet.
- Dark mode is not defined yet. Do not improvise one: define dark tokens here first (ink background, paper text, `--accent-soft`).
- Share tokens through a common package once `packages/` exists (see PLANNING.md); until then copy the variables from `main.css`.

## 10. Do / Don't

| Do | Don't |
| --- | --- |
| Cream paper, black ink, one red accent | Gradients, glow, blue/purple, dark-navy hero |
| Serif headlines with italic emphasis | One sans family for everything |
| Ruled lists, ledgers, numbered sections | Grids of identical rounded cards with icon tiles |
| Stamp, scrawl, highlighter, hand underline (few) | Decorative stickers everywhere |
| Typeset, labelled illustrations | Fake dashboards, metrics, logos, quotes |
| Honest status words | Presenting unbuilt features as live |
| `AppSelect` | Native `<select>` or restyled hacks |
| Visible focus, keyboard support | Removing outlines, hover-only affordances |

## 11. Checklist before shipping a UI change

1. Only tokens from `main.css`; fonts are the four above; no new colors.
2. No emoji; icons are Lucide; no icon tiles or card grids.
3. Strings added to both `vi` and `en` in `useCopy.ts`.
4. Correct at 1280px and 390px, no horizontal scroll, long Vietnamese text does not clip.
5. Keyboard reachable, visible focus, Esc closes popovers; contrast verified; reduced motion respected.
6. No invented numbers or claims; status wording matches `ROADMAP.md`.
7. The maker line is present (top strip, makers section, footer) and unchanged.
8. `cd web && npx nuxt build` passes; screenshot reviewed on desktop and phone.
